# 진주 대기질 경보 프로그램 (Jinju Air Alert)

공공데이터 기반 진주시 대기오염 탐구의 후속 활동으로 제작한, 노약자·호흡기 질환자를 위한 3단계 대기오염 경보 프로그램입니다. 에어코리아 실시간 자료(진주시 대안동·상대동·상봉동·정촌면 측정소)를 받아 안심(초록)·주의(노랑)·외출 자제(빨강)로 판정하고, 큰 글씨와 신호등 색으로 행동 요령을 안내합니다. 경보가 나빠지면 팝업 알림을 띄우며 1시간마다 자동 갱신됩니다.

## exe 파일 받는 방법 (GitHub Actions 자동 빌드)

1. GitHub에서 새 저장소를 만듭니다. 이름 예시: `Jinju_Air_Alert` (Public 권장, Private도 무방)
2. 파일 3개를 업로드합니다. `.github/workflows/build.yml`은 경로가 정확해야 하므로, 저장소에서 **Add file → Create new file**을 누르고 파일 이름 칸에 `.github/workflows/build.yml`을 그대로 입력한 뒤 내용을 붙여넣는 방식이 가장 안전합니다. `jinju_air_alert.py`와 `README.md`는 **Add file → Upload files**로 올리면 됩니다.
3. 업로드(commit)하면 **Actions 탭**에서 `build-exe` 워크플로가 자동 실행됩니다. 초록 체크가 뜰 때까지 2~4분 정도 기다립니다.
4. 완료된 워크플로를 클릭한 뒤 아래 **Artifacts** 영역에서 `JinjuAirAlert-exe`를 내려받습니다. zip 안에 `JinjuAirAlert.exe`가 들어 있습니다.
5. 실행 시 Windows SmartScreen 경고가 나오면 "추가 정보 → 실행"을 누릅니다. (서명되지 않은 개인 제작 프로그램이라 나타나는 정상적인 경고입니다.)

## 인증키 발급 (실시간 데이터 연동)

1. 공공데이터포털(data.go.kr) 가입 후 "한국환경공단_에어코리아_대기오염정보" 활용신청을 합니다. 신청 즉시 개발계정(일 500건)이 승인됩니다.
2. 마이페이지에서 **일반 인증키(Decoding)** 를 복사합니다. (Encoding 키를 넣으면 인증 오류가 납니다.)
3. 프로그램 하단 입력칸에 붙여넣고 "저장"을 누르면 exe 옆 `config.json`에 저장되어 다음 실행부터 자동 적용됩니다.
4. 인증키가 없으면 데모 데이터로 화면 구성을 확인할 수 있습니다.

## 경보 기준 (민감계층 보수 기준)

탐구 보고서에서 확인한 진주시의 이원적 위험 구조(겨울·봄 미세먼지, 여름 오존)를 반영하여, 환경부 예보 등급보다 보수적으로 설정했습니다. 초미세먼지는 15/35㎍/㎥, 미세먼지는 30/80㎍/㎥, 오존은 0.030/0.090ppm을 경계로 안심·주의·외출 자제를 판정하며, 네 측정소 중 가장 나쁜 값을 기준으로 삼습니다. 계절에 따라 환기·외출 시간대 안내 문구가 달라집니다.

## 코드 구성

외부 라이브러리 없이 파이썬 표준 라이브러리(urllib, tkinter)만 사용하여 빌드 실패 요인을 없앴습니다. 로컬에서 바로 실행하려면 `python jinju_air_alert.py`만으로 동작합니다.
